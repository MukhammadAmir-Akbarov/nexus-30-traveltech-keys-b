# Запасной ролик и кадры для слайдов

`demo-reel.mp4` — 42 секунды, 12 кадров по 3,2 секунды, без звука.

Это **страховка, а не замена живого показа**. Ролик молчит намеренно: ценность
демо — в голосе, который ведёт по сценарию. Ставить его в слайд как есть не надо;
надо либо начитать поверх (текст ниже, тайминг совпадает с кадрами), либо
держать наготове на случай, если упадёт сеть, туннель или проектор.

`frames/` — те же 12 кадров отдельными PNG для слайдов.

## Как пересобрать

Кадры сняты по сценарию из [../DEMO.md](../DEMO.md) на светлой теме, 1280×800
(последний — телефон 390×800, дополнен полями до общего размера). Сборка:

```bash
# в папке с кадрами
for f in *.png; do printf "file '%s'\nduration 3.2\n" "$f"; done > list.txt
ls *.png | tail -1 | sed "s/^/file '/;s/$/'/" >> list.txt
ffmpeg -f concat -safe 0 -i list.txt -vf "fps=25,format=yuv420p" \
  -c:v libx264 -preset slow -crf 23 -movflags +faststart demo-reel.mp4
```

Если снимаете заново — держите одну тему на всех кадрах, кроме последнего:
пёстрый ролик читается как набор скриншотов, а не как один продукт.
